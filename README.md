# oto 音楽プレイヤー

スマホのホーム画面に追加して使う、YouTube Music風の音楽プレイヤー(PWA)。アプリ本体はビルド不要の静的サイトで、YouTubeからの取り込みだけ別のサーバーを使います。

- アプリ: https://oto-app-beryl.vercel.app/ (Vercel)・ https://miyazakitakumi-724.github.io/oto-app/ (GitHub Pages)
- YouTube取り込み用サーバー: Render(`server/`)。接続先は `js/config.js` の `YT_API_ENDPOINT`

## このアプリについて
- 自分と友達が使うために作った、個人開発のアプリです。一般向けのサービスとして公開・運営するものではありません
- 企画とデザインの判断以外は、AI(Claude)だけで開発しています。コードはすべてAIが書いたものです

## できること
- 端末の音楽ファイル(MP3・M4A など)を取り込み、端末内(IndexedDB)に保存
- MP3のタグから曲名・アーティスト・ジャケットを自動で読み取り
- YouTube動画のURLから音声を取り込み(進み具合の表示・キャンセルつき)
- ライブラリを曲・アーティスト・アルバムごとに表示、検索
- プレイリスト(ドラッグで並べ替え)、シャッフル、リピート、次に再生(キューの並べ替え・削除)
- お気に入り、最近再生した曲、よく聴く曲、今月のまとめ(再生回数・聴いた時間)
- スリープタイマー(時間指定・この曲が終わるまで)
- 削除は「元に戻す」で取り消せる
- ロック画面・通知からの操作とバックグラウンド再生(Media Session API)
- 一度開けばオフラインでも起動(Service Worker)
- 音量調整(サウンドタブと再生画面。iPhoneでも効くよう音声処理の中で下げる)
- サウンド設定: クロスフェード、無音カット、音量の自動調整、ナイトモード、5バンドのイコライザー(80Hz〜10kHz、±15dB、プリセット8種)、ホール残響、再生速度(音程をそのままにするか、速度に合わせて変えるかを選べる)
- ワンタップ加工: Slowed + Reverb(ゆっくり・低く・響きを足す)、ナイトコア(速く・高く)
- 元の音と比べる: サウンドタブのボタン(PCでは B キー)を押している間だけ、効果をすべて止めた元の音を鳴らす
- 立体音響: 8Dオーディオ(HRTFで頭のまわりを回す)、バーチャルサラウンド、ステレオ拡張。効果の強さを調整できる
- ボーカルと伴奏の音量を別々に調整(カラオケ・ボーカル強調など)。周波数ごとに中央の音を見分ける処理(`js/center-worklet.js`、AudioWorklet)で分ける
- 再生画面のビジュアライザー
- Googleドライブ同期: 各自のドライブの「oto」フォルダに曲とプレイリスト・お気に入りを保存し、スマホとPCで同期(`js/config.js` にOAuthクライアントIDを設定)。ドライブに保存済みの曲は「この端末から音声を消す」で端末の容量を空けられ、再生するときにドライブから読み込む
- 再生回数と今月のまとめは端末ごとに記録(同期しない)

| キー | 操作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 5秒戻る / 進む |
| Shift + ← / → | 前の曲 / 次の曲 |
| + / − | 音量 |
| M | ミュート |
| L | お気に入り |
| S / R | シャッフル / リピート |

| Esc | 閉じる・戻る |
| ? | 操作の一覧 |

## YouTubeからの取り込みについて
YouTubeの利用規約は、YouTubeが用意したボタン以外での動画・音声のダウンロードを認めていません。この機能は自分と友達の個人利用に限っています。

- `server/`: Render で動かす取り込み用サーバー(Docker、yt-dlp)。Vercel 版と GitHub Pages 版のアプリからの取り込みを許す。環境変数 `YOUTUBE_COOKIES`(YouTubeのCookie)、`ALLOWED_ORIGIN`(ほかに許すURLをカンマ区切りで追加。`*` ならどこからでも)
  - 起動時と6時間ごとに、yt-dlp を最新の nightly 版へ自動で更新する(YouTube の変更で取り込めなくなるのを防ぐ)。今の版は `/health` で見られる
  - 取り込めなかったときは、理由(Cookie切れ・年齢制限・非公開など)に合わせたメッセージを返す。Cookie が切れていたら、Cookie なしでもう一度試す
- `api/youtube.js`: Vercel の関数版(@distube/ytdl-core)

### YouTubeのCookieを長持ちさせる
Render のようなクラウドのサーバーから取り込むと、YouTube に「ボットではない確認」を求められます。そのため、ログインした Cookie を `YOUTUBE_COOKIES` に入れておきます。

普段のブラウザから書き出した Cookie は、すぐ使えなくなります。そのブラウザで YouTube を開いている間に、YouTube が Cookie を作り直すためです。次の手順で書き出すと長持ちします(yt-dlp の公式の手順)。

1. Chrome の拡張機能「Cookie-Editor」の詳細を開き、「シークレット モードでの実行を許可する」をオンにする(Edge なら「InPrivate で許可する」)
2. シークレットウィンドウ(Ctrl+Shift+N)で YouTube を開き、ログインする。yt-dlp で使ったアカウントは停止されるおそれがある(yt-dlp の注意書き)ので、取り込み専用のサブアカウントがおすすめ
3. 同じタブで https://www.youtube.com/robots.txt を開く(シークレットのタブはこの1つだけにする)
4. Cookie-Editor の Export → JSON でコピーする
5. **ログアウトせずに**シークレットウィンドウを閉じる(ログアウトすると、書き出した Cookie も使えなくなる)
6. Render のサービスの Environment で `YOUTUBE_COOKIES` に貼り付けて保存する

## ローカルで試す
```
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開く。
