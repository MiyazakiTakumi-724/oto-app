# oto 音楽プレイヤー

スマホのホーム画面に追加して使う、YouTube Music風の音楽プレイヤー(PWA)。ビルド不要の静的サイトなので、このフォルダをそのまま GitHub Pages に置けば動きます。

https://miyazakitakumi-724.github.io/oto-app/

## このアプリについて
- 自分と友達が使うために作った、個人開発のアプリです。一般向けのサービスとして公開・運営するものではありません
- 企画とデザインの判断以外は、AI(Claude)だけで開発しています。コードはすべてAIが書いたものです

## できること
- 端末の音楽ファイル(MP3・M4A など)を取り込み、端末内(IndexedDB)に保存
- MP3のタグから曲名・アーティスト・ジャケットを自動で読み取り
- プレイリスト、シャッフル、リピート、次に再生、検索
- ロック画面・通知からの操作とバックグラウンド再生(Media Session API)
- YouTube動画のURLを追加して、YouTube公式の埋め込みプレイヤーで再生
- 一度開けばオフラインでも起動(Service Worker)
- 音量調整(サウンドタブと再生画面。iPhoneでも効くよう音声処理の中で下げる)
- サウンド設定: クロスフェード、無音カット、音量の自動調整、ナイトモード、5バンドのイコライザー(プリセット付き)、ホール残響、再生速度(音程はそのまま)
- 立体音響: 8Dオーディオ、バーチャルサラウンド、ステレオ拡張
- ボーカルと伴奏の音量を別々に調整(カラオケ・ボーカル強調など)
- 再生画面のビジュアライザー
- Googleドライブ同期: 各自のドライブの「oto」フォルダに曲とプレイリストを保存し、スマホとPCで同期(`js/config.js` にOAuthクライアントIDを設定)

YouTubeからの音声ダウンロードや変換は規約違反になるため対応していません。

## ローカルで試す
```
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開く。
