# Oto 音楽プレイヤー

スマホのホーム画面に追加して使う、YouTube Music風の音楽プレイヤー(PWA)。ビルド不要の静的サイトなので、このフォルダをそのまま GitHub Pages に置けば動きます。

## できること
- 端末の音楽ファイル(MP3・M4A など)を取り込み、端末内(IndexedDB)に保存
- MP3のタグから曲名・アーティスト・ジャケットを自動で読み取り
- プレイリスト、シャッフル、リピート、次に再生、検索
- ロック画面・通知からの操作とバックグラウンド再生(Media Session API)
- YouTube動画のURLを追加して、YouTube公式の埋め込みプレイヤーで再生
- 一度開けばオフラインでも起動(Service Worker)

YouTubeからの音声ダウンロードや変換は規約違反になるため対応していません。

## ローカルで試す
```
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開く。
