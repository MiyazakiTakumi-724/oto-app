Oto プライバシーポリシー

最終更新日: 2026年10月19日

Oto(以下「本アプリ」)は、端末の音楽ファイルを再生するためのウェブアプリです。本アプリが扱う情報とその使い方を説明します。

端末に保存する情報

取り込んだ音楽ファイル、曲名などの情報、プレイリスト、サウンド設定は、利用者の端末のブラウザ内にだけ保存されます。開発者のサーバーに送られることはありません。

Googleドライブ同期で扱う情報

利用者が「Googleでログインして同期」を選んだ場合に限り、Googleアカウントでのログインを通じて、次の目的でGoogleドライブを利用します。

  • 利用者自身のGoogleドライブに「Oto」フォルダを作り、音楽ファイルとライブラリ情報(曲名・プレイリストなど)を保存・読み込みします。
  • 同期中の表示のため、ログインしているGoogleアカウントのメールアドレスを読み取ります。

本アプリが利用する権限は、本アプリが作成したファイルだけにアクセスできるもの(drive.file)です。利用者のドライブにあるそれ以外のファイルを読むことはできません。これらの情報は利用者のブラウザとGoogleの間だけでやり取りされ、開発者を含む第三者のサーバーに送信・保存されることはありません。

本アプリによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

YouTube

YouTubeの動画は、YouTube公式の埋め込みプレイヤーで再生します。再生時にはYouTube(Google)が情報を収集する場合があり、その扱いはGoogleのプライバシーポリシーに従います。

同期をやめる・データを消す

本アプリの「同期をやめる」でいつでも同期を止められます。本アプリへのアクセス許可はGoogleアカウントの設定から取り消せます。ドライブ上のデータは「Oto」フォルダを削除すると消えます。端末のデータは、ブラウザのサイトデータを削除すると消えます。
