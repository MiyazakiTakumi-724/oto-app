oto プライバシーポリシー

最終更新日: 2026年11月21日

oto(以下「本アプリ」)は、端末の音楽ファイルやYouTubeから取り込んだ音声を再生するためのウェブアプリです。本アプリが扱う情報とその使い方を説明します。

端末に保存する情報

取り込んだ音楽ファイル、曲名などの情報、プレイリスト、お気に入り、再生回数や聴いた記録、サウンド設定は、利用者の端末のブラウザ内に保存されます。下の「YouTubeからの取り込み」で説明する通信を除き、開発者のサーバーに送られることはありません。

Googleドライブ同期で扱う情報

利用者が「Googleでログインして同期」を選んだ場合に限り、Googleアカウントでのログインを通じて、次の目的でGoogleドライブを利用します。

  • 利用者自身のGoogleドライブに「oto」フォルダを作り、音楽ファイルとライブラリ情報(曲名・プレイリストなど)を保存・読み込みします。
  • 同期中の表示のため、ログインしているGoogleアカウントのメールアドレスを読み取ります。

本アプリが利用する権限は、本アプリが作成したファイルだけにアクセスできるもの(drive.file)です。利用者のドライブにあるそれ以外のファイルを読むことはできません。これらの情報は利用者のブラウザとGoogleの間だけでやり取りされ、開発者を含む第三者のサーバーに送信・保存されることはありません。

本アプリによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

YouTubeからの取り込み

YouTubeの動画のURLを入力して「取り込む」を選ぶと、そのURL(動画ID)を開発者が運営する取り込み用サーバーに送ります。サーバーはYouTubeから音声と曲名・投稿者名などの情報を取得して利用者の端末に返すだけで、音声ファイルを保存しません(処理のために一時的に作るファイルは、送り終えたあとに削除します)。ジャケットに使うサムネイル画像も、このサーバーを通して取得します。

取り込み用サーバーは、外部のサービス(Render、Vercel)の上で動いています。本アプリを開いたときには、サーバーをすぐ使えるようにするための通信も行います。これらのサービスは、通常の運用のためにアクセスの記録(IPアドレスなど)を残す場合があります。また、取り込みに失敗したときは、原因を調べるためにサーバーのエラー記録に動画のURLが残る場合があります。

曲名を補うためにYouTube(Google)のサーバーへ直接問い合わせる場合があり、その扱いはGoogleのプライバシーポリシーに従います。以前のバージョンで追加した埋め込み形式のYouTubeの曲は、YouTube公式の埋め込みプレイヤーで再生します。

同期をやめる・データを消す

本アプリの「同期をやめる」でいつでも同期を止められます。本アプリへのアクセス許可はGoogleアカウントの設定から取り消せます。ドライブ上のデータは「oto」フォルダを削除すると消えます。端末のデータは、ブラウザのサイトデータを削除すると消えます。
